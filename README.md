# commercial-harvest

> **Public data repo** — ADF&G Alaska Commercial Salmon Harvest by Management Area
> Part of the [alaskafishdata](https://github.com/alaskafishdata) public data network.

## Data Files

| File | Description | Updated |
|------|-------------|---------|
| `data/live-commercial.json` | Regional commercial harvest (harvest lbs, ex-vessel value, permits) | Daily |

## Coverage

8 ADF&G management areas: Bristol Bay, Southeast Alaska, Prince William Sound, Kodiak, Area M, Cook Inlet, Chignik, Norton Sound.

## Source

- **ADF&G Division of Commercial Fisheries**  
  https://www.adfg.alaska.gov/index.cfm?adfg=commercialbyspecies.salmon

```
https://raw.githubusercontent.com/alaskafishdata/commercial-harvest/main/data/live-commercial.json
```
